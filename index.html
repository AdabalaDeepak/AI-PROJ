Setup guide
Everything you need to deploy Soulmate end-to-end
🚀 Getting started
1

Clone & install

Run npm install in the project root. You need Node.js 18+ and Redis running locally (or use Upstash for serverless Redis).

2

Fill in your .env

Copy .env.example to .env and fill in all four API keys: WhatsApp, Twilio, Anthropic, and your public BASE_URL.

3

Create a Meta App & WhatsApp Business account

Go to developers.facebook.com → Create App → WhatsApp. Get your Phone Number ID and generate a permanent access token. Set your webhook URL to https://yourdomain.com/webhook.

4

Set up Twilio

Sign up at twilio.com. Buy a phone number with voice capability. Copy your Account SID and Auth Token into .env. Trial accounts must verify recipient numbers first.

5

Deploy to a server

Deploy on Railway, Render, or any VPS. Make sure your server has a public HTTPS URL — Meta requires HTTPS for webhooks. Use ngrok for local testing.

6

Verify webhook & test

In Meta dashboard, click "Verify" on your webhook. Then use the Test Call tab above to place a live call. Finally text your WhatsApp number to test end-to-end!
